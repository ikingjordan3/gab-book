# Genomics & Applied Bioinformatics

This is the companion book for **Genomics & Applied Bioinformatics** at Georgia Tech.
Each chapter follows a pair of lectures and has three parts:

- **Modules** are short sections of text, one per idea taught in lecture, with the key figures and equations.
- **Self-check quizzes** come at the end of each module. Pick an answer to see whether it is right and why.
  Nothing is graded or recorded, and you can retake a quiz as many times as you like.
- **A lab notebook** for each chapter lets you do the analysis yourself in Python, R and command-line
  tools such as PLINK and BWA.

See {doc}`setup` for how to run the lab notebooks.

```{note}
This book is a work in progress and chapters are added as the course is taught. If you find a mistake,
please open an issue with the GitHub button at the top of any page.
```
